# Customer-Churn-Analysis-Excel

# Project Overview

This project analyzes customer churn data to uncover insights about why customers leave and how churn rates vary across demographics and usage patterns. The goal is to create a clear, interactive Excel dashboard that helps identify churn drivers and provide data-driven insights.

This case study was completed as part of a guided project on DataCamp, but the analysis and dashboard design are my own work.

# Dashboard Overview

![Image](https://github.com/user-attachments/assets/2fe7255d-aedd-4178-b521-7f359672ed34)

The dashboard provides an executive-level summary of customer churn, combining key KPIs, churn reasons, demographic insights, data usage patterns, and geographic analysis. It highlights where churn is most severe and points to customer segments and regions that require targeted retention strategies.
